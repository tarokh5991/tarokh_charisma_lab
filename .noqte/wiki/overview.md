# Overview

TAROKH Charisma Lab یک اپلیکیشن آموزشی فارسی برای توسعهٔ کاریزماست که مسیر آموزشی CLEAR، تمرین‌های عملی، مربی هوشمند و منتورینگ آنلاین را ارائه می‌کند. رابط React/Vite فعلی پروتوتایپ محصول است و زیرساخت MVP با Supabase آغاز شده است.

مدل دادهٔ اولیه برای حساب‌ها، محتوای آموزشی، ارزیابی، پیشرفت، پلن‌ها، پرداخت‌ها، گفتگوهای مربی و منتورینگ در [[entities/mvp-data-model]] تعریف شده است. تا اتصال پروژهٔ Supabase و تنظیم متغیرهای محیطی، این مدل فقط به‌صورت migration در مخزن نگهداری می‌شود.

ساختار محتوای نسخهٔ اول در `docs/course-content-v1.md` تثبیت شده است: ۱۵ درس در پنج فصل CLEAR با ترتیب Confidence، Listening، Expression، Awareness و Rapport. قالب انتشار درس در `docs/lesson-template.md` و سهمیهٔ مربی، منتورینگ و قواعد عملیاتی در `docs/mvp-service-rules.md` مشخص شده‌اند.

کنترل کیفیت فاز ۷ با اسکریپت‌های type-check، بررسی فرمت و تست قراردادی Node تعریف شده است؛ workflow انتشار GitHub Pages پیش از build همهٔ آن‌ها را اجرا می‌کند.
