# بکاپ و بازیابی Supabase

## هدف

این روند از داده‌های PostgreSQL پروژه یک خروجی رمزدار در مقصد ذخیره‌سازی مورد تأیید تیم می‌سازد و پیش از تحویل، ساختار آن را اعتبارسنجی می‌کند. کلیدها و رشتهٔ اتصال هرگز در مخزن یا گزارش بکاپ ثبت نمی‌شوند.

## پیش‌نیازها

- ابزارهای PostgreSQL شامل `pg_dump` و `pg_restore`
- مقدار `SUPABASE_DB_URL` در محیط اجرای محلی یا سرور عملیات؛ این مقدار باید فقط از تنظیمات امن Supabase دریافت شود.
- یک محل ذخیره‌سازی خصوصی با نگه‌داری حداقل ۳۰ روز؛ پوشهٔ محلی `backups/` فقط محل موقت است و commit نمی‌شود.

## گرفتن بکاپ

```bash
export SUPABASE_DB_URL='...'
./scripts/backup-supabase.sh
```

اسکریپت خروجی custom-format با پسوند `.dump` تولید می‌کند، با `pg_restore --list` آن را اعتبارسنجی می‌کند و فایل SHA-256 کنار آن می‌سازد. پس از پایان، دو فایل را به محل ذخیره‌سازی خصوصی تیم منتقل کنید و کپی محلی موقت را حذف کنید.

## زمان‌بندی عملیات

- هر روز یک بکاپ کامل بگیرید.
- بکاپ روزانه را ۳۰ روز و بکاپ ماهانه را ۱۲ ماه نگه دارید.
- پس از هر migration یا تغییر مهم داده، یک بکاپ خارج از برنامه بگیرید.
- مسئول عملیات، ماهی یک‌بار نتیجهٔ بکاپ و اندازهٔ غیرعادی فایل را بررسی می‌کند.

## آزمون بازیابی

هر سه ماه یک‌بار، جدیدترین بکاپ را فقط در یک پروژهٔ آزمایشی خالی بازیابی کنید. هرگز دستور بازیابی را مستقیماً روی پروژهٔ production اجرا نکنید.

1. در مقصد آزمایشی، داده‌های موجود را بررسی و در صورت نیاز پاک‌سازی کنید.
2. ساختار فایل را پیش از بازیابی بررسی کنید:

   ```bash
   sha256sum -c tarokh-<timestamp>.dump.sha256
   pg_restore --list tarokh-<timestamp>.dump
   ```

3. با رشتهٔ اتصال **محیط آزمایشی** بازیابی را انجام دهید:

   ```bash
   pg_restore --dbname="$TEST_SUPABASE_DB_URL" --no-owner --no-privileges tarokh-<timestamp>.dump
   ```

4. ورود یک حساب آزمایشی، خواندن درس‌ها، پیشرفت، سفارش و گزارش مدیریت را بررسی کنید؛ سپس تاریخ و نتیجهٔ آزمون را ثبت کنید.

## رخداد بازیابی

در رخداد واقعی، ابتدا نوشتن داده و migrationها را متوقف کنید، جدیدترین بکاپ سالم را انتخاب کنید و بازیابی را ابتدا در محیط آزمایشی تأیید کنید. بازیابی production فقط با تأیید مسئول محصول و مسئول فنی انجام می‌شود؛ پس از آن مسیرهای ورود، پرداخت، پیشرفت، مربی و پنل مدیریت بررسی می‌شوند.
