# قالب استاندارد درس — TAROKH Charisma Lab

هر درس باید کوتاه، عملی و قابل‌پیگیری باشد و با ساختار زیر منتشر شود.

## مشخصات پایه

| فیلد | استاندارد |
| --- | --- |
| شناسه | شمارهٔ یکتا از ۱ تا ۱۵ |
| محور CLEAR | یکی از Confidence، Listening، Expression، Awareness یا Rapport |
| زمان | ویدیو ۸ تا ۱۲ دقیقه؛ تمرین ۵ تا ۱۵ دقیقه |
| پیش‌نیاز | درس قبلی، مگر درس اول |
| وضعیت انتشار | پیش‌نویس، آمادهٔ بازبینی یا منتشرشده |

## ساختار محتوا

1. **ویدیوی درس:** یک مسئلهٔ مشخص، یک مدل رفتاری و یک نمونهٔ واقعی را آموزش دهد.
2. **خلاصهٔ عملی:** حداکثر سه نکتهٔ قابل به‌کارگیری بلافاصله بعد از ویدیو.
3. **تمرین بیرون از محصول:** یک اقدام کوچک، قابل مشاهده و متناسب با زندگی روزمره.
4. **ثبت تمرین:** کاربر یک پاسخ متنی کوتاه، چک‌لیست یا لینک فایل ثبت می‌کند.
5. **معیار تکمیل:** فقط بعد از ثبت تمرین، درس کامل و درس بعدی باز می‌شود.
6. **تمرین اختیاری با مربی:** فقط در درس‌های ۵، ۷، ۸، ۱۲ و ۱۴ سناریوی متن‌محور داشته باشد.

```md
[یک چارچوب کوتاه و قابل یادآوری]

### تمرین امروز
[یک اقدام مشخص در یک موقعیت مشخص]

### ثبت تکمیل
[آنچه کاربر باید در محصول ثبت کند]

### معیار قبولی
[شرط روشن تکمیل تمرین]
```

## کنترل کیفیت پیش از انتشار

- نتیجهٔ یادگیری با تمرین همان درس قابل سنجش باشد.
- تمرین در کمتر از ۱۵ دقیقه و بدون ابزار خاص قابل انجام باشد.
- لحن درس محترمانه، غیرقضاوتی و بدون وعدهٔ نتیجهٔ تضمینی باشد.
- تمرین هیچ‌کس را به فشار، فریب یا نادیده‌گرفتن مرز دیگران تشویق نکند.
